# NightShift

Small atmospheric indie-game prototype built with Godot 4.

## Current prototype

- 3D test room with collision
- 2D pixel-style character inside the 3D world
- Smooth WASD movement
- Angled orthographic follow camera
- Simple night lighting

## Run the project

1. Clone or download this repository.
2. Import project.godot in Godot 4.
3. Press F5 or the play-project button.

## Controls

| Action | Key |
| --- | --- |
| Move forward | W |
| Move left | A |
| Move backward | S |
| Move right | D |
